Better Carts makes hauling with Carts more pleasant with quality-of-life features, all configurable in-game

[size=4][b]Features[/b][/size]
[list]
[*][b]Chain Overflow[/b] - when a full Cart picks up an item, it is passed to the next Cart in the chain with a free slot. Nothing is left behind until every chained Cart is full[/*]
[*][b]Bucket Priority[/b] - prefer grabbing an empty Bucket when unloading a Cart[/*]
[*][b]Cart Release Fix[/b] - releasing a pulled Cart never grabs a different Cart on the same press[/*]
[*][b]Cart Capacity[/b] - set how many items the vanilla Carts can carry (0-64, default 4). The Mercury cart-capacity blessing adds a configurable bonus on top (0-64, default 1), and Eject Overflow drops anything above the limit beside the Cart when a world loads. Modded Cart types are not covered[/*]
[*][b]Cart Overlays[/b] - the item count is shown above a Cart carrying more than 5 items, and a Cart that comes loose from the chain by itself says so. Counts for ordinary capacity and for empty Carts can be turned on too[/*]
[*][b]Collect Range[/b] - Carts automatically pick up loose items within a configurable range (0-10 tiles, default 2). 0 = vanilla[/*]
[*][b]Deposit Range[/b] - Carts deposit matching cargo into Material Storages within range (0-10 tiles, default 2). 0 = vanilla[/*]
[*][b]Connect Range[/b] - free Carts are pulled toward a Cart the player is pulling once in range (0-10 tiles, default 2). 0 = vanilla[/*]
[*][b]Stockpile Range[/b] - Carts take resources from building Output stockpiles within range, into free slots and empty Buckets on the Cart (0-10 tiles, default 2). 0 = vanilla[/*]
[/list]

[size=4][b]Configuration[/b][/size]
All settings (master toggle, per-feature toggles etc.) are configured from the [b]Mod Settings[/b] button in the main menu (added by [b]Mod Settings Menu[/b]), or in [b]BepInEx/config/com.beesq.romestead.bettercarts.cfg[/b]

[size=4][b]Multiplayer[/b][/size]
[b]Server-side[/b] - only the host needs the mod, joining players do not need anything installed
[list]
[*]Chain Overflow[/*]
[*]Cart Capacity - the host's values apply to everyone, but each player needs the mod to SEE cargo beyond the vanilla slots[/*]
[*]Collect Range[/*]
[*]Deposit Range[/*]
[*]Connect Range[/*]
[*]Stockpile Range[/*]
[/list]

[b]Client-side[/b] - applies to each player that has the mod installed
[list]
[*]Bucket Priority[/*]
[*]Cart Release Fix[/*]
[*]Cart Overlays - the cargo count appears for every player with the mod, and the disconnect message is shown to whoever was pulling the Cart[/*]
[/list]

[size=4][b]Install[/b][/size]
Extract the zip into your Romestead folder (the mod files land in BepInEx/plugins/BetterCarts), then launch the game through Steam

[size=4][b]Notes[/b][/size]
[list]
[*]The mod stores nothing in your save unless a Cart actually carries more than the game allows on its own - more than 4 items, or more than 5 with the Mercury blessing[/*]
[*]Eject Overflow is the only part of the mod that moves your cargo: on world load, a Cart over its capacity drops the surplus beside itself[/*]
[*]High capacity values can cause stutter and stack cargo into a tall tower above the Cart[/*]
[*]Before removing the mod, change Carts Capacity and Mercury's blessing values back to vanilla, leave Eject Overflow on, and load each affected world once so extra cargo is released[/*]
[*]Deposit Range takes only matching resources from Cart cargo[/*]
[*]Stockpile Range takes only from Output stockpiles, a building's input storage is never drained[/*]
[/list]
